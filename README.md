# Inverse Methods for Atmospheric Sounding

Inverse Methods for Atmospheric Sounding is the "bible" for retrieval science in earth observation. It goes through all the methods commonly applied in inverse methods and retrievals for earth and planetary atmospheres. 

This repository is the collection of notes on the chapters and methods outlined in the book, as well as some coded methods in python. Rodgers (2000) is famously abstract, and leaves a lot as "exercises to the reader", this repo will hopefully help with that in the future.

## Usage

Chapters will have `.md` files of notes for material, including equations, plots, and background theory. Any key methods will be explored using `.ipynb` notebooks and calling functions detailed in `src/`. This is in no way meant to be optimal or performant as far as code quality goes, just a collection of notes. A good starting point.
